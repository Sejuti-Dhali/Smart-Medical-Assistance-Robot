# Image provenance and evidence status

The four PNG files in `hardware/circuit_diagrams/` are newly drawn logical wiring diagrams based on the supplied report. They are **not** photographs, exact physical breadboard layouts, or independently verified electrical schematics.

`media/prototype/` and `media/demonstrations/` are intentionally empty: a fabricated robot photograph or fabricated sensor terminal reading must not be presented as experimental evidence. Original authorized photos or actual recorded outputs can be added later.

The full project report is intentionally not included.
